# Dr. Arvind — Maxillofacial Surgeon Website

A modern, SEO-optimized website built for Dr. Arvind, designed to establish a strong digital presence for a professional maxillofacial surgeon.

The platform focuses on:

* Professional branding
* Patient trust & credibility
* Appointment booking
* Service showcase
* Mobile-first performance
* SEO optimization
* Smooth user experience

# Installation & Setup

## Clone Repository

```bash
git clone https://github.com/notAmecarmel/arvindNouv.git
```

## Navigate to Project

```bash
cd arvindNouv
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

---

# Build for Production

```bash
npm run build
```
